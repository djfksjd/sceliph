# 16차: 사진 2장 시각적 자기 비판 루프 (개발 단계에서 종료, 2026-10-28)

## 방식
1. `fitTurntableCameras`로 두 사진(프레임 0, 18)의 카메라를 함께 맞춘다.
   - 방위차 +90°는 고정한다. 개발용 데이터에서 정답 GLB로 정했다(비대칭 조명에서 IoU +90° 0.80, −90° 0.56).
   - 고도, 거리, 화각은 공유하고, 화면 오프셋은 사진마다 따로 둔다.
2. 두 사진 위에 IR 렌더를 겹친다(부품별 색, 놓친 제품 = 자홍, 바깥 모델 = 시안 윤곽).
   - 마스크는 SAM 결과에서 흰 배경을 뺀다. 열린 프레임 사이가 잘못 칠해지던 문제를 고친 것이다.
3. Sonnet이 사진 2장, 겹침 그림 2장, 현재 IR을 보고 IR을 고친다(최대 2라운드).
4. 두 사진 평균 실루엣 IoU가 0.01 이상 오를 때만 받아들인다. 정답은 채점에만 쓴다.

- 거부되면 원래 IR을 유지하므로 손해는 없다. 수락된 4건 중 3건은 정답 지표 대부분이 개선됐다.
- 두 설정에서 수락된 항목이 겹치는 것은 B07B4SB2D9 하나뿐이다. 효과가 일관되지 않다.

### 추가: 부품 하나만 고치기 + 3개 후보 중 최고 (`dev-focus-best3.json`, $0.91)
- 매 라운드 실루엣 차이가 가장 큰 부품 하나만 고치게 하고, 수정안 3개 중 실루엣 이득이 가장 큰 것을 고른다.
- 수락은 1/10(B07B78G1BW: F@2% 0.61→0.72, IoU 0.81→0.83)이었다. 나머지 7건은 실루엣 이득이 0~0.01로 작았다. 국소 수정이 안전하지만 이득은 작다.
- 후보 30개를 정답과 직접 비교했다(`dev-focus-candidates-vs-gt.txt`). F@2%는 좋아진 것 6, 나빠진 것 6이었다.
  - 실루엣 이득이 0에 가까운데 정답 지표가 크게 떨어진 경우가 있었다. 실링팬 날개는 IoU −0.20, B07TY5GXBQ는 F@2% −0.09였다.
  - 즉 작은 실루엣 이득은 정답 개선을 예측하지 못한다. 문턱(0.01)을 낮추면 해롭다.

## 판정
사전에 정한 진행 조건(수락률 ≥ 30%)에 못 미쳐 평가용(test) 실행 없이 종료한다. 기록할 결론은 세 가지다.
- 두 사진 카메라 공동 피팅은 동작하고, 재사용할 수 있다(`src/engine/photo-part-color.ts`).
- 효과의 상한은 'LLM이 겹침 그림을 보고 일관되게 고치는 능력'이 정한다. 지금 Sonnet으로는 개선이 드물고 비일관적이다.
- 국소 수정과 3개 후보 중 고르기도 시도했지만 수락은 1/10이었다. 실루엣 게이트로는 작은 수정의 품질을 가려내지 못한다. 이 방향은 더 이상 진행하지 않는다.
