# 8차 계획 반대 검토 요약 (2026-10-27)

초안: `plan-draft.md`. 검토자 둘에게 서로 다른 관점을 맡겼고, 둘 다 저장소를 읽기 전용으로만 봤다. 원문은 세션 기록에 있고, 아래는 결정에 반영한 지적이다.

## Opus (방법론, 목표 정합성): 수정 후 승인
- **치명적**
  - v3를 같은 합성 장면 5개로 검증하면 장면에 맞춘 튜닝이 그대로 "통과"로 나온다. v2 악화 5건 중 3건이 box-post 한 장면이었다.
  - MAP 사전분포를 "악화 건수 최소화"로 고르면 가장 작은 σ, 곧 "피팅 끄기"가 뽑힌다. prior 비용(`priorWeight·z²`)이 실루엣 손실(약 0.008~0.024)보다 커서 형상이 움직이지 못한다.
  - 0a(정답에서 시작하는 진단)는 이미 oracle 실행으로 답이 나와 있다(형상 변화 0, `calibration-v2/oracle`).
  - ABO에서 앵커 절차가 정의돼 있지 않다. 높이 끝점은 실루엣 경계라 MoGe 깊이가 없고, GT로 투영하면 정보가 샌다.
  - 입력으로 준 GT 높이를 채점에서 빼지 않았다.
- **요구**
  - ABO를 맨 앞으로 옮기고 v2 피팅 설정은 동결한다.
  - 기준선 B0(상자)와 B1(실루엣)을 추가한다.
  - 모든 후보에 같은 정렬을 적용한다.
  - 새 시점이 거울상으로 겹치지 않게 다시 고른다.
  - 표본은 30건 이상으로 늘리고, dev와 test를 사전에 나눈다.
  - 꼬리가 두꺼운 사전분포를 쓰고 파레토로 판단한다.
  - 새 합성 장면을 만든다.
- **목표 정합성**
  - 사진 프로토콜이 기본 도형 5종만 노출한다. 형상 어휘가 상한을 정한다.
  - 높이↔깊이 맞바뀜은 다중 시점이 정공법이다.
  - 합성 실험은 LLM에 부품 목록을 줬다.
  - 겉보기(텍스처) 지표는 비어 있다.
- **대신 등록할 기준**
  - final−llm IoU 중앙값 ≥ 0.02이고 CI 하한 > 0
  - B0/B1을 이김
  - 입력하지 않은 축 오차 중앙값 ≤ 10%, p75 ≤ 25%
  - 악화 비율 ≤ 20%

## Fable (실현 가능성, 데이터 사실): 조건부 진행
- **확인한 사실**
  - spin은 턴테이블 촬영 사진이다(bucket README). 다만 배경을 지우고 물체에 맞춰 잘라냈고, EXIF가 없고, 고도·화각 정보도 없다.
  - spin과 3D 모델의 연결은 `listings_*.json.gz`의 `spin_id`·`3dmodel_id`에 있다.
  - GLB는 미터, Y-up, 바닥 y=0이다. 리스팅 치수와 맞는다.
  - faces 최댓값이 1150만이라 상한 규칙이 필요하다.
  - 라이선스는 CC-BY-4.0이다.
- **설계 지적**
  - 보류 프레임마다 GT로 카메라를 피팅하는 채점은 비싸고 불필요하다. GT와 후보를 같은 합성 카메라로 렌더해 비교하라.
  - 0a는 6차 oracle과 중복이다.
  - 범주를 하드서피스로 제한하고 faces ≤ 200k 조건을 넣어라.
  - 입력으로 준 높이는 채점에서 빼고 x/z만 채점하라.
  - "실제 사진"이 아니라 "카탈로그 사진"이라고 적어라.
- **새 코드 추정**: GLB 로더 60줄, Chamfer 100줄, ABO 채점 200줄.

## 반영 결과
- 0a(정답에서 시작하는 진단), 0b(MAP 사전분포), v3(합성 재검증)는 이번 차수에서 뺐다.
- ABO를 먼저 하고, v2 피팅 설정은 동결했다.
- 기준선 B0, B1을 추가했다.
- 채점은 공통 합성 카메라 8방위(20°), 바닥·중심 정렬과 같은 yaw 탐색, IoU, Chamfer, F-score로 했다.
- 크기 오차는 x/z만 기준에 넣었다.
- 앵커 대신 리스팅 높이를 extent prior와 초기 스케일로 썼다. GT는 쓰지 않았다.
- LLM에 부품 목록을 주지 않았다.
- dev 10건으로 어휘(기본 5종 vs lathe·extrude 추가)를 고른 뒤, test 30건 기준을 사전 등록했다.
- 다중 시점(프레임 18)과 텍스처 지표는 다음 차수로 미뤘다.
