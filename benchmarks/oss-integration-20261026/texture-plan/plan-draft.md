# 13차 계획 초안: 사진 투영 텍스처 + 조명 보정 (2026-10-27)

## 배경 (지금까지의 증거)
- 10차 겉모습 지표: LLM IR의 albedo ΔE00 중앙값은 6.8~7.7이다. 회색은 22.0, 시점별 최선의 단일 색(정답 albedo 기준 오라클)은 2.9다. 질감 비율 지표는 부품 경계도 '질감'으로 센다. 같은 형상의 전후 비교에만 쓸 수 있다.
- 11차 dev: 사진에서 부품 단색만 가져오는 방법은 이득이 0이었다. 사진 값에는 노출과 그늘이 섞여 있고, 한 장으로는 밝기 스케일이 정해지지 않는다. LLM 색에 노출을 맞추면 변화가 0이 된다. 실루엣은 앞뒤를 구분하지 못해 LLM 시점 사전분포가 필요했다.
- 남은 오차는 부품 안의 무늬와 색 변화(나뭇결 등)로 추정한다. 이번 차수는 이 무늬를 옮기려는 시도다.

## 제안 방법
1. **카메라**: 11차의 실루엣 카메라 맞춤을 재사용한다(LLM 시점 ±60°, 사전분포). 실루엣 IoU가 0.8 미만이면 해당 항목은 텍스처를 입히지 않는다.
2. **투영 UV**: 부품 형상을 인덱스 없는 삼각형으로 만들고, 삼각형마다 가시성을 판정한다. 기준은 세 꼭짓점이 깊이 버퍼상 보이고, 사진을 향하며, 시선과의 각도가 75° 미만인 것이다.
   - 보이는 삼각형: UV를 사진 좌표로 준다. 아틀라스에 사진의 부품 영역 크롭을 넣는다.
   - 안 보이는 삼각형: 그 부품의 보이는 영역에서 만든 타일 패치로 UV를 보낸다. 근거 상태는 '추론'으로 둔다.
3. **조명 보정(delighting)**: 부품별로 큰 가우시안 블러로 휘도의 저주파 성분(그늘)을 추정해 나누고, 고주파 무늬만 남긴다. 밝기 스케일은 11차처럼 LLM 색 휘도에 전역 노출로 맞춘다.
4. **내보내기**: 부품마다 baseColor 텍스처 하나를 굽는다(최대 1024px). GLB 재열기 검증과 Khronos 검증을 통과해야 한다. IR 쪽은 `material.referenceProjection`과 비슷한 텍스처 참조 필드를 쓰거나 새 필드를 만든다(스키마 결정 필요).
5. **근거 표시**: 투영된 면은 'photo-projected', 나머지는 '추론'.

## 평가 (사전 등록 예정)
- 데이터: 9b test r1의 a1(사진 1장) IR 33건. 10차에서 측정만 했고 튜닝에는 쓰지 않았다. 개발용은 9b dev 10건이다.
- 비교: 같은 형상에서 'LLM IR(단색)'과 '투영 텍스처 IR'을 짝지어 비교한다. 지표는 10차 렌더러(readPixels 경로)로 8개 시점을 잰다.
- 기준 후보:
  - T1: 질감 비율 차이의 중앙값 > 0이고 CI 하한 > 0
  - T2: albedo ΔE00가 0.5 넘게 나빠지지 않을 것(중앙값)
  - T3: 조명 SSIM 차이의 중앙값 > 0
  - T4: 사진 시점에서 다시 렌더한 결과와 사진의 ΔE00(정합 확인, 기술적 지표)
- 실루엣 IoU 0.8 미만으로 건너뛴 항목은 '변화 없음'으로 포함한다.

## 위험
- 사진 1장이므로 대부분의 면이 '추론'이다. 새 시점 평균에서는 효과가 작을 수 있다.
- 정합 오차 때문에 무늬가 밀리고, 가는 부품에서 배경이 섞일 수 있다.
- 실제 사진의 색 보정과 정답 텍스처의 차이가 남는다.
- GLB 용량이 커진다(부품당 텍스처).
- IR 스키마를 바꿔야 할 수 있다(이미지 파일 참조, 출처 해시).
- 10차의 질감 비율 지표는 hue 통제에서 실패(V2)했다. 지표 자체의 타당성도 일부만 확인된 상태다.
