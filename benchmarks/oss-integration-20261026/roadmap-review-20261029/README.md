# 로드맵 공동 검토: Claude × Codex (2026-10-29)

엔진 고도화가 얼마나 남았는지, 어떻게 진행할지 2라운드로 논의했다.
- Codex는 `codex exec`(계정 기본 모델 gpt-6-astra, reasoning xhigh, read-only sandbox)로 실행했다. gpt-5.5와 gpt-5.4는 이 계정에서 지원되지 않았다.
- Codex 답에 끌려가지 않도록, Claude의 견해를 1라운드 전에 파일로 고정했다(`00-`).
- Codex는 저장소의 문서, 벤치마크, 코드를 직접 읽었다.

## 확인된 사실 (Claude가 Codex 지적을 검증)
- 9~16차가 재사용한 안내문(`abo-photo/protocol-test.json` guide)은 연산 7개(roundedBox, cylinder, sphere, torus, tube, lathe, extrude), 부품 2~16개, 색·거칠기·금속성만 알려 준다.
  - 스키마에는 booleanCSG, implicitSurface, surfacePatch, ellipsoid, bladeLoft, `material.surface` 마감이 더 있다.
  - 지금까지의 ABO 수치는 엔진 능력의 부분집합만 쟀다.
- `quality:gate` exit 1의 Blender 엄격 수락 실패는 최종 GLB의 Khronos info 23건(UNUSED_OBJECT)과 연결된다. 오류와 경고는 0이다.

## 합의
- 전체 완료율 하나는 방어할 수 없다. 대상 분포, 허용 수정 시간, 비교 대상이 정해지지 않았기 때문이다. 앞서 보고한 60%는 가중치에 의존한 판단이었다.
- 같은 ABO 33건이 10·13·14·15차에서 반복 노출됐다. 이 연구선의 최종 확증에는 새 test가 필요하다.
- 측정상의 약점:
  - F@5%는 관대하다.
  - detailLog·spreadLog는 엉뚱한 무늬도 보상한다.
  - 16차에서 실루엣 이득이 정답 개선을 예측하지 못했다.
- B3(투영)를 B2(타일링) 성공에 묶은 것은 잘못이었다. 둘은 다른 가설이다.
- 사람 평가 설계
  - 1인 소유자의 보정 판단 60개를 보정 20개와 잠금 검증 40개로 나눈다.
  - 다른 모델 계열로 judge 패널을 만들고, 소유자와 75% 이상 일치하면 개발용 선별에 쓴다.
  - 최종 성공 판정은 소유자가 직접 한다.
  - 일반 사용자 수용성은 주장하지 않는다.
- 전용 생성기 없이 진행한다. 주장 범위는 "선정 분포에서 참조 충실도, 편집 계약, 소유자 수용 기준을 충족한 비율"이다. 생성기와 동등하다는 주장은 하지 않는다.

- 병행 작업: Blender UNUSED_OBJECT 정리와 보존 검증(좁은 수정)
