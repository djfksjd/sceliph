## 관찰
네 건 모두 구조가 맞는다.
- 줄에 매달린 펜던트
- 꺾인 팔과 헤드
- 아치형 기둥과 갓
- 5날개와 조명 볼

IR은 기존 연산(tube 곡선, lathe, cylinder, roundedBox)으로 이 구조를 이미 표현했다. 낮은 IoU와 F@2%는 다음 두 가지에서 온다.
- 가는 줄·기둥의 실루엣 민감도
- 작은 부품의 크기·위치 오차: 펜던트 몸통이 크고, 갓의 수평 위치가 다르다.

**결론**: 이 표본에서는 '가는 구조용 새 연산(어휘)'이 병목이라는 근거가 약하다. 병목은 작은 부품의 배치와 크기 정밀도다.
